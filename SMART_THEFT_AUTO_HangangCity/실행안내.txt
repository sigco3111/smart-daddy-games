SMART THEFT AUTO - 한강시티 이야기

실행 방법
1. 압축을 풉니다.
2. index.html 파일을 더블클릭합니다.
3. 시작 화면에서 START 버튼을 누르면 바로 플레이할 수 있습니다.

중요
- 처음 실행할 때 인터넷 연결이 필요합니다. 게임 화면을 그리는 Three.js 라이브러리를 CDN에서 불러옵니다.
- 크롬(Chrome) 또는 엣지(Edge) 최신 버전 권장.
- 키보드가 한글 입력 상태면 조작이 잘 안 될 수 있으니 영어 입력 상태로 바꿔주세요.
- 시작하면 기본 배경음악(SMART FM 신스웨이브)이 자동으로 깔립니다. R키로 라디오 채널을 바꾸거나 OFF 할 수 있습니다.

기본 조작
W A S D: 이동 / 운전
마우스: 시점
좌클릭: 사격
E: 차량 탑승 / 하차
Space: 점프 / 핸드브레이크
Shift: 달리기
1 2 3: 무기 교체
R: 라디오 채널 변경 / OFF
C: 조작법 보기
P: 일시정지

게임 팁
- 차 옆에서 E를 누르면 탑승합니다.
- 범죄를 저지르면 별이 올라가고 경찰이 추격합니다.
- 4성부터는 경찰 헬기가 출동합니다.
- 초록 총 마커에 가면 체력과 로켓 탄약을 무료로 보급받을 수 있습니다.
